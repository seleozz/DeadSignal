# DeadSignal
## Об игре
>Главный герой — бездомный стример, который живёт на донаты и снимает трэш-контент. Однажды он запускает среди зрителей аукцион: «Куда я поеду на следующий стрим?».
>
>Зрители донатят и предлагают места. Побеждает странный вариант — заброшенный зимний лес, о котором ходят местные легенды.

### Цель игры:
Исследовать загадочный лес и искать способ выбраться из ловушки. 
 
### Тип проекта:
💻Видеоигра (Windows)

### Цель проекта:
Работая в команде, создать программный продукт, который заинтересует игроков от 12 лет своей атмосферой напряжения, страха и неопределённости.
